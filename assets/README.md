# Assets Folder

Place your images and media files here.

## Required Image

### profile.jpg
- **Your profile photo**
- Recommended size: 400x400px or larger
- Format: JPG, PNG, or WebP
- Aspect ratio: Square (1:1)
- File size: < 500KB recommended

**Add your photo:**
```bash
cp /path/to/your/photo.jpg profile.jpg
```

## Tips

1. **Optimize images** before uploading to reduce load times:
   - Use tools like TinyPNG, Squoosh, or ImageOptim
   - Target < 200KB per image when possible

2. **Use descriptive filenames** if adding more images:
   - Good: `project-medical-imaging.jpg`
   - Bad: `IMG_1234.jpg`

3. **Backup original high-res images** elsewhere before optimizing

4. If images are missing, the website will show placeholder graphics automatically
